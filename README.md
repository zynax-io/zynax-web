# zynax-web

Website for [Zynax](https://github.com/zynax-io/zynax) — a declarative, cloud-native,
engine-agnostic control plane for AI agent workflows.

## Status

Scaffold. No site framework has been chosen yet.

## Local development

```bash
git clone git@github.com:zynax-io/zynax-web.git
cd zynax-web
```

## Contributing

Work on a branch, then open a pull request against `main`.

```bash
git checkout -b feat/my-change
git push -u origin feat/my-change
```
